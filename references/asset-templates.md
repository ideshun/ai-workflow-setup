# 工作流与配置骨架

公共内容统一放 `.agents/`，专属配置按 adapter 定路径。公共文件只写项目事实、流程和阅读路由，不绑定 IDE，不写当前宿主、会话状态、客户端版本/开关或核验快照；必要原生文件可用真实相对路径导航。不写空文件、虚构路径或其他仓库业务规则。

## 1. 初始化必交

| # | 配置项 | 默认路径 |
| --- | --- | --- |
| 1 | 根入口 | adapter 规定（如 `CODEBUDDY.md` / `AGENTS.md`） |
| 2 | 手册 | `.agents/AI-CODING.md` |
| 3 | 知识 ≥ 1 | `.agents/knowledge/*.md` |
| 4 | 规则 ≥ 1 | `.agents/rules/*.md` |
| 5 | Skills | `.agents/skills/<name>/SKILL.md` |
| 6 | 模板 | `.agents/templates/*.md`（有 Skill 时） |
| 7 | 原生 Agent | adapter 路径（目标支持、有审查流程且用户需要时） |

按用户范围和项目证据选用；不适用或无依据的项注明原因，不为凑齐集合编造内容。

## 2. 入口

```text
# 项目 AI 工作入口

## 工作边界
核对根目录与已有改动；区分只读/计划/实施。
批准范围内执行；报告验证与未验证项。

## 按需读取
<任务> → `.agents/rules/<规则>.md` → 必要时 `.agents/knowledge/<知识>.md`

## 可用流程
列出已生成 Skills 路径；无原生发现则显式读取。

## 安全与交付
不读凭证/私人历史；不自动提交；静态阅读≠测试通过。
```

换成真实命令与路由。同角色已有入口先确定维护源，目标端必要入口按明确阅读要求复用；不复制另一套公共规则。

## 3. 公共手册

```text
# 项目 AI 工作流使用手册

## 从哪里开始
实际项目入口及其职责；按任务读取规则、流程和知识，不全量预加载。

## 文件导航
已存在的入口、规则、Skills、知识和模板的相对路径及用途。

## 日常任务
定位、实施、审查、知识维护的方法；使用真实项目命令和流程路径。

## 维护与验收方法
入口维护共同边界与阅读路由；Skills维护流程；知识随实现更新。
检查修改范围、引用有效性和验证证据；不预填本次运行结果。
```

客户端特有命令、发现/刷新步骤和开关不写入公共手册；确有需要时写原生目录内获准的适配说明，否则在交付总结说明。不默认新建适配说明，不把 `.agents/` 路径存在写成全客户端自动加载保证。

## 4. 规则

每条一个主题：适用范围、应保持行为、待确认、验证边界。来源必须是本项目扫描。

正文写 `.agents/rules/`；原生触发仅在 schema 已核实且确需时按 adapter 适配，明确唯一正文维护源。不支持引用时先确认同步方式，不把一行链接当作原生导入。

## 5. 知识

结构：适用范围 → 来源路径/符号 → 当前实现 → 待确认 → 更新触发。

按项目实际记录技术栈、目录、入口、关键模块和构建约束；请求/鉴权、i18n/样式仅在项目存在时记录，不把当前实现自动提升为强制规范。可拆多页。

## 6. Skill

```yaml
---
name: <按项目命名>
description: <适用与不适用；触发条件具体>
---
```

正文：输入、步骤、暂停、输出。常用：功能交付、只读审查、知识同步。

## 7. 原生 Agent

frontmatter 用 adapter 已核实格式。正文：接收 Diff/目标；读入口与审查 Skill；缺 Diff 降级；只读护栏。

## 8. 模板

任务约定、审查交接：目标、范围、证据、验证、下一动作。

## 9. 禁止写入项目

本 Skill 的 adapter、inventory.py、评测产物、私人聊天、凭证、其他项目事实。
